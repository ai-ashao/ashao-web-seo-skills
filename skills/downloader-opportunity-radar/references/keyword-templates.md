# Keyword Universe & Intent Permutations

v3 rule: **Never size a downloader niche from one head keyword.**

## 1. Core platform action permutations

Always test:

- `{platform} downloader`
- `{platform} download`
- `download {platform}`

These may have materially different volume and SERPs.

## 2. Core asset permutations

For each plausible asset `{asset}`:

- `{platform} {asset} downloader`
- `{platform} {asset} download`
- `download {platform} {asset}`
- `download {asset} {platform}`

Add `save {platform} {asset}` only when users naturally use `save` for the platform.

## 4. Example: Threads core universe

A correct first-pass universe includes at least:

- threads downloader
- threads download
- download threads
- threads video downloader
- threads video download
- download threads video
- download video threads
- threads image downloader
- threads image download
- download threads images
- threads photo downloader
- threads profile picture downloader
- threads dp downloader
- threads dp download
- threads pfp downloader
- threads gif downloader
- threads carousel downloader

Do not conclude `Threads demand = volume(threads downloader)`.

## 6. Bulk intents

Only retain when product/search intent is real:

- bulk {platform} downloader
- batch {platform} downloader
- download all {platform} images
- {platform} zip downloader

## 7. Secondary modifiers

Do NOT use these to define the core market unless independent intent is verified:

- free
- online
- hd
- mp4
- without watermark
- without login
- iphone
- android
- chrome

## 8. Locale expansion

Do not translate mechanically into every language.

Use competitor regions and local keyword databases to discover forms such as:

- local-language equivalent of download/downloader;
- English `download/downloader` queries used in non-English markets;
- platform-specific slang.

Store locale variants separately from English core volume to avoid misleading totals.

## 9. Canonicalization

For every raw keyword store:

- `canonical_intent`
- `platform`
- `asset`
- `action_pattern`
- `locale`
- `volume_source`
- `volume`
- `ranking_page`

Group semantically close variants, but retain material queries when SEO tools show distinct search demand or SERPs.
