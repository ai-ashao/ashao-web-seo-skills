# reference-website-builder v2.1

One reference-page Skill with four modes:

- `analyze` — extract reusable patterns, no code by default;
- `prototype` — build a fast static/interactive prototype;
- `adapt` — integrate an approved pattern into the real project;
- `full` — explicit high-fidelity reconstruction/migration with provenance and release gates.

The default remains the lightest mode that satisfies the request.

## v2.1 reconstruction kernel

When high fidelity is explicitly required, v2.1 adds:

1. collision-resistant `site-key` / `page-key` output isolation;
2. deterministic computed-style and layered-asset extraction recipes;
3. measured multi-state interaction capture;
4. extract -> spec -> bounded builder parallelization;
5. a pre-dispatch completeness gate;
6. equivalent-viewport visual QA and route-preservation checks.

These rules strengthen `prototype`/`full` without turning ordinary competitor analysis into a heavyweight workflow.

The former `competitive-ui-reverse-engineering` and `adapt-reference-site` responsibilities remain consolidated here.
