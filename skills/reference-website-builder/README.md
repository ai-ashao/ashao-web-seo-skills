# reference-website-builder v2

One reference-page Skill with four modes:

- `analyze` — extract reusable patterns, no code by default;
- `prototype` — build a fast static/interactive prototype;
- `adapt` — integrate an approved pattern into the real project;
- `full` — explicit high-fidelity reconstruction/migration with provenance and release gates.

The default is the lightest mode that satisfies the request. The former `competitive-ui-reverse-engineering` and `adapt-reference-site` responsibilities are consolidated here.
